# Credits

Every file under `src/assets/` has a row here: where it came from, who made it,
and its licence. CLAUDE.md rule 12 is the policy: **CC0 or CC-BY only**. Nothing
from a commercial game, nothing share-alike, nothing marked personal use. A row
is written *before* its file is copied in. `spec/assets.test.ts` fails on any
file under `src/assets/` without a row here, and on any row whose licence isn't
allowed.

Paths are relative to `src/assets/`. A path ending in `/` covers everything
under it.

## The party: Superpowers "RPG Battle System" asset pack

Pixel-art side-view battlers made by **Pixel-boy** at **Sparklin Labs** for the
open-source Superpowers engine. This is original art, not taken from any
commercial game. The repository's licence is CC0 1.0 Universal (`LICENSE.txt`;
GitHub reports `CC0-1.0`), and its README says: "The assets in this repository
are created at Sparklin Labs by Pixel-boy. They are released under the Creative
Commons Zero (CC0) license… You can use the assets found in this repository in
your own games, even commercial ones. Attribution is not required but
appreciated." It is credited here anyway.

repo and rule 12 doesn't reach them. They are listed so nobody mistakes them
for something we may copy in. Both are SIL Open Font License 1.1, which is
**not** CC0 or CC-BY, so **never self-host them under `src/assets/`**.
